# SkyPilot

Пилотский клиент сети виртуальной авиации **SkyNetwork** для **Microsoft Flight Simulator 2020 и 2024**.

SkyPilot связывает симулятор с FSD-сервером сети

- отправляет вашу позицию, высоту, скорость, положение самолёта и код ответчика каждые 5 секунд;
- показывает в симуляторе других пилотов сети как AI-самолёты. Модель подбирается по типу ВС и авиакомпании, движение плавное, с экстраполяцией между обновлениями;
- показывает текстовые сообщения на частотах, на которые настроены COM1/COM2, и личные сообщения в отдельных вкладках;
- забирает план полёта, поданный на сайте SkyNetwork, и передаёт его на сервер (см. [`docs/website-api.md`](docs/website-api.md));
- показывает список ATC рядом. Двойной щелчок настраивает на частоту диспетчера радио с включённым TX;
- COM1 и COM2 с кнопками RX (приём) и TX (передача). Частоту и код ответчика можно ввести прямо в поле и нажать Enter;
- голосовая радиосвязь через голосовой сервер SkyNetwork: приём на COM1/COM2, передача по клавише PTT, радиоэффекты (см. [Голосовая связь](#голосовая-связь));
- поддерживает режим ответчика Standby / Mode C и IDENT;
- отвечает на запросы диспетчерских клиентов: тип ВС, имя, ping.

## Команды

| Команда | Действие |
|---|---|
| `текст` | сообщение на частоту радио с включённым TX |
| `.com1 118.100`, `.com2 121.500` | настроить радио |
| `.x 7000` (`.xpdr`, `.squawk`) | код ответчика |
| `.ident` | IDENT |
| `.modec` | переключить Standby / Mode C |
| `.msg AFL123 текст` | личное сообщение |
| `.wallop текст` | вызвать супервайзера: сообщение уходит всем супервайзерам в сети |
| `.disconnect` | отключиться |
| `.help` | справка |
